# Cover and rear display glance

On compatible Android displays the app shows a compact course/deadline/online-payment surface. Settings configure sections and offer previews. Display classification excludes unfolded landscape windows. The main navigator stays mounted across fold/unfold, and shortcuts are consumed by the visible surface. Policy acceptance gates personal data on both surfaces; the glance never changes main-display brightness.

The implementation retains upstream iOS tab stacks, online Apple Watch support, dependency pins, release version, signing and update channel. It does not add a display permission on other platforms. Offline payment remains in the full campus-card UI; previews and source checks do not verify camera scanning on every physical rear screen.

Regression coverage includes classification, compact layouts, privacy, foreground/payment lifecycle and shortcut routing. Actual vendor display routing, folding and QR scans still require compatible hardware.
