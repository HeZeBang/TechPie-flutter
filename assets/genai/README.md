# GenAI demo image

`demo-campus.png` is a generated local test fixture showing a red bicycle, a
campus library, trees and a reflective pond. It lets image rendering and zoom
checks distinguish decoded pixels from loading, error and empty placeholders.
It is labeled “本地测试图片” in the UI. Local fixture mode does not call the school
image API or consume school quota. Live service images retain their own URLs.

Created on 2026-10-22 using the built-in image generation tool.

## Generation prompt

Use case: illustration-story
Asset type: a real raster test image bundled in a campus app to verify chat image rendering and zoom, not a UI mockup or placeholder.
Primary request: a recognizable sunny university campus scene.
Subject: a modern cream and red-brick library beside a small reflective pond, a bright red bicycle on a tree-lined path in the foreground, green trees and a blue sky with soft white clouds.
Style/medium: polished, richly detailed editorial digital illustration, natural proportions, crisp textures and varied colors, visibly meaningful content even as a small chat thumbnail.
Composition/framing: square image, entire scene framed clearly, foreground bicycle and middle-distance building easy to distinguish, no border.
Constraints: no text, no logos, no watermark, no UI controls, no blank areas, no generic image icons.
